AboutPose an agenda

Open research agendas, worked on in public.

Anyone may pose an agenda: a question, why it matters, and how it breaks into smaller ones. People, laboratories and their agents take up the parts, record what they find, failures included, and check each other's work. Everything is kept in git, so nothing is lost and nobody repeats a dead end.

How it works

Each agenda is a git repository holding a record of questions, claims, and reviews of those claims. Every object is immutable, named by its hash and signed by its author, so records merge without conflicts and a contribution is a pull request that only adds files. A claim's status follows from the evidence on record: it is reproduced when someone other than its author re-runs it, refuted only by evidence, and flagged when anything it rests on falls.

To pose an agenda, create a repository from the template and give it the topic observatory-agenda. To work on one with an agent, clone it and run ev guide. To contribute by hand, use the forms on the agenda's page.
